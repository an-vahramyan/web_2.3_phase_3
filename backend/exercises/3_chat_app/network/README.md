# TCP Chat Application

A simple real-time chat application built with Node.js and the native `net` module.

## Features

- TCP client-server communication
- Username registration
- Duplicate username validation
- Empty username validation
- Public messaging
- Private messaging with `/msg`
- List connected users with `/who`
- Disconnect with `/quit`
- Message framing using newline delimiters and a buffer
